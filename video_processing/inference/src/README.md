This folder contains the core source code for the windsurfing video processing pipeline, including object detection, multi-object tracking, stabilization, and visualization.

### Core Components

*   **windsurf_video_processor.py**: The main orchestrator that manages the end-to-end pipeline:
    *   Runs object detection and ReID embedding extraction.
    *   Computes camera stabilization transforms (GMC).
    *   Executes the tracking stack (preprocessing, ILP/Greedy tracking, and post-processing).
    *   Generates annotated videos, individual track crops, and metadata for the player.
*   **common_types.py**: Fundamental data structures used across the system:
    *   `Point`, `Keypoint`, and `BoundingBox`: Geometric primitives with support for interpolation, scaling, and IoU.
    *   `Detection`: A single observation containing a bbox, embedding, and keypoints (boom/mast).
    *   `Track`: A collection of detections over time with methods for embedding averaging and temporal analysis.
*   **orientation_fixer.py**: Utility to automatically correct video orientation:
    *   Uses a YOLO classification model to detect if a video is rotated (0°, 90°, 180°, 270°).
    *   Applies corrective rotation using FFmpeg to ensure the horizon is upright.
*   **settings.py**: Central configuration for model paths, detector thresholds, tracking hyperparameters (ILP costs, Kalman filter weights), and output dimensions.

### Entry Points

*   **local_inference_main.py**: CLI tool for batch processing videos.
    *   Supports glob patterns for input files.
    *   Utilizes `ProcessPoolExecutor` for parallel video processing.
    *   Flags for generating individual videos, drawing annotations, and stabilization.
*   **local_player_main.py**: Launches the PySide6-based interactive player to visualize tracks and metadata generated by the inference pipeline.

### Subfolders

*   **[motion](./motion)**: Global Camera Motion (GMC) estimation and Kalman Filter implementations for motion compensation.
*   **[player](./player)**: PySide6 UI components and state management for the interactive video player.
*   **[tracking](./tracking)**: Object detection wrappers and various MOT algorithms (ILP, OC-SORT, Greedy).
*   **[util](./util)**: Low-level math, video I/O wrappers, and performance caching decorators.
*   **[visualization](./visualization)**: Tools for drawing annotations, stabilizing frames, and splicing individual track highlights.
