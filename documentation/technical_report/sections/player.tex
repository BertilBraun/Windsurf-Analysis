\section{Frame-Accurate Delivery}
\label{sec:player}

Identity-consistent tracks are useful only if the browser applies metadata to the
frame that produced it. Ordinary HTML video exposes media time rather than stable
frame identity, so the WebCodecs path~\cite{webcodecs} defines a canonical index by
ordering packets by presentation timestamp and sequence number. Preview seeks from a
preceding keyframe and decodes forward. Export decodes independently but maps each
sample to the same index, resynchronizing by timestamp when necessary. The shared
index and crop geometry preserve frame correspondence through preview and export;
this is a delivery constraint rather than a tracking contribution.
