\title{\vspace{-8mm}\textbf{Identity-Consistent Analysis of Long-Shot Windsurfing Video}\\
\large An Offline System for Tracking and Rider-Relative Stabilization}
\author{Bertil Braun\\\href{mailto:contact@bertil-braun.de}{contact@bertil-braun.de}}
\date{}

\begin{document}
\maketitle
\vspace{-5mm}

\begin{abstract}
Long-shot windsurfing video combines small targets, large camera pans, prolonged
overlaps, and rapidly changing backgrounds.  The desired output is not a generic MOT
trace but a separate, stable rider-relative video for each surfer; one false identity
merge can invalidate an otherwise useful result.  We present an offline analysis
system that detects surfers, forms conservative local tracklets, links them globally
with camera-compensated motion and a foreground-masked sail-color descriptor, and
uses two rig keypoints to drive a stable virtual camera.  The tracking stage is
evaluated on 21 manually reconstructed development videos containing 41,004 retained
observations.  On this fixed-observation protocol, the production system achieves
0.957 pairwise precision, 0.918 recall, and 0.937 F1, compared with 0.792 F1 for
OC-SORT and 0.828 for BoT-SORT.  It reduces fragmentation excess to 42, from 845 and
244 respectively, while retaining nine contaminated tracks.  Ablations and a visual
audit show that conservative geometric vetoes remove many catastrophic false links;
the remaining failures concentrate at crossings and visually near-duplicate sails.
The result is an applied computer-vision system report: tracking receives comparative
quantitative evaluation, while pose-based stabilization is documented as the
downstream system output and evaluated qualitatively.
\end{abstract}
